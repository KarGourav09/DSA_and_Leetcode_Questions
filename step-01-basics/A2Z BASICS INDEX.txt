C++ practice input convention:
- Array programs read n followed by n values.
- String programs use cin for token input and getline when spaces matter.
- Boolean programs print 1 for true and 0 for false.
- Pattern programs read n.

Compile one file from its directory:
g++ -std=c++17 -Wall -Wextra "file.cpp" -o program
